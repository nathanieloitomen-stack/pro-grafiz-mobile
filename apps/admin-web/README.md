# Pro_Grafiz Admin Web

Next.js + TypeScript staff administration surface (branch/central admin
functions not covered by the mobile staff surface — see Master Spec
Section 6 for V1 scope split).

## Status

PG-001 scaffolding only: one placeholder route, no auth, no data
fetching, no design system. `package.json` dependency versions were
declared without access to a live npm registry — run `npm install` then
check for updates before relying on exact versions.

## Setup

```bash
npm install
npm run dev
```
